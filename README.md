# Dead Spots · 指型練習簿

給自己用的吉他和弦指型練習工具。純靜態網頁，沒有後端。

- **指型庫**：在指板上記錄指型、標出根音，自動算出每個音的級數（1 / 3 / 5 / 7 / 延伸音），不顯示絕對音名。可把不熟的指型標成盲區。
- **擲骰子**：依風格（indie / dream pop / trip hop / post-punk / shoegaze）加權抽出和弦進行、調性、BPM，並從指型庫挑指型（盲區 > 自訂 > 內建）。附節拍器。
- **盲區練習**：名字→指型、指型→級數兩種題型，依「卡住」比例調整出題權重。

## 資料存在哪

存在瀏覽器的 localStorage，每台裝置、每個瀏覽器各自一份。清除網站資料、無痕模式、Safari 7 天未造訪（加到主畫面可避免）都會清掉。請用「指型庫 → 備份 → 複製 JSON」定期備份。
